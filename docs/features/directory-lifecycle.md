# Удаление и архивирование филиалов и групп

Доступ: администратор и суперадминистратор, раздел «Справочники».

## Правила

- Кнопки «В архив», «Восстановить» и «Удалить» находятся рядом с записью.
- Архив сохраняет детей, историю участия, посещения, абонементы, счета и оплаты.
- Перед архивированием группы нужно перевести действующих детей (включая паузу и пробных), отменить предстоящие незавершённые занятия и завершить заявки на пробное.
- При архивировании группы её шаблоны расписания тоже архивируются.
- Перед архивированием филиала нужно архивировать все его группы.
- Восстановление возвращает статус «Активен». Шаблоны расписания автоматически не восстанавливаются. Группу нельзя восстановить раньше филиала.
- Полностью удалить можно только запись без связанных данных, включая архивные группы, табели, задачи, пробные, абонементы и историю участия. При наличии связей сервер перечислит их и предложит архив.
- Для удаления нужно ввести точное название. Отмена не изменяет данные.
- Действия фиксируются в журнале аудита и ограничены текущей школой. Проверки выполняются на сервере, включая прежние запросы изменения статуса.

## Проверка перед выпуском

1. Администратор и суперадминистратор видят действия; тренер не может вызвать API.
2. Пустая запись удаляется после ввода названия; при отмене остаётся.
3. Запись с историей не удаляется.
4. Архивирование блокируется при незавершённых зависимостях и объясняет причину.
5. Пустая группа архивируется и восстанавливается; её история сохраняется.
6. Филиал с действующей группой не архивируется, с архивными — архивируется.
7. Страница и подтверждения доступны с телефона.

Изменения не требуют миграции базы данных. Публикация — после локальной приёмки.
