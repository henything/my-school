# Смена расписания и контроль начислений

## Изменить дни группы

1. Откройте «Расписание», блок «Изменить расписание с даты».
2. Выберите группу, дату начала, новые дни и время. Укажите причину.
3. Нажмите «Предварительный расчёт». Изменения ещё не сохранены.
4. Если прежний индивидуальный день ребёнка исчезает, выберите новый день либо все занятия группы. Затем повторите расчёт. Будущие индивидуальные планы тоже требуют выбора.
5. Проверьте отменяемые и создаваемые занятия, сохранённые табели, количество занятий и суммы до/после. Записи на пробные, которые нужно перенести, блокируют применение.
6. Подтвердите изменения. Если есть случаи для ручной финансовой проверки, отдельно подтвердите создание задач.

Старое расписание сохраняется как история с датой окончания, новое начинает действовать с выбранной даты. Занятия с отметками сохраняются. Повторная генерация учитывает периоды шаблонов. Если данные изменились после расчёта, система попросит получить свежий расчёт.

## Что происходит с оплатой

| Ситуация | Результат |
| --- | --- |
| Неоплаченный счёт без начатой оплаты | Пересчёт вместе с абонементом, с сохранением применённых зачётов и льготы |
| Оплаченный месяц стал дешевле | Денежный платёж и счёт сохраняются; разница становится зачётом на следующие начисления |
| Оплаченный месяц стал дороже | Задача администратору; автоматической доплаты нет |
| Родитель уже начал оплату | Задача для ручной проверки |
| Счёт был полностью покрыт зачётами, денежных оплат не было, сумма выросла | Может вновь появиться сумма к оплате, показанная в расчёте |

Неиспользованный остаток денежного зачёта сохраняется. При повторном открытии нулевого счёта дополнительный ранее неиспользованный остаток не списывается сверх показанного расчёта; его можно применить отдельно или использовать в следующем начислении. Возврат денег через платёжную систему это действие не проводит.

## Разобрать справки и расхождения

1. Откройте «Балансы» или «Задачи», блок «Контроль начислений».
2. Посмотрите ребёнка, группу, причину, ответственного и срок.
3. Для болезни выберите подтверждение либо обычный платный пропуск и укажите основание.
4. Для расхождения счёта откройте предварительный пересчёт в «Балансах». Существующие счета после решения по справке сами не переписываются.

Ежедневная сверка обновляет задачи. Ручное закрытие задачи не устраняет причину: если она сохранилась, задача откроется снова. Справка не становится подтверждённой автоматически по истечении срока.

В аналитике «Ожидают оплаты» означает, что срок ещё не истёк; «Просрочили оплату» — что срок прошёл. Эти показатели учитывают непогашенные счета за все месяцы. Один родитель может попасть в обе категории по разным счетам.

## Ручная проверка на локальном стенде

Используйте отдельную QA-базу и группу «00 Для ручной проверки».

1. Выберите дату 01.11.2026 и вторник/четверг, 10:00–11:00.
2. Получите расчёт: система должна попросить заменить индивидуальную среду ребёнка.
3. Выберите «Все занятия группы» и повторите расчёт.
4. Ожидайте 4 → 8 занятий, счёт 1 350 → 3 150 ₽: ранее применённый зачёт 450 ₽ сохраняется.
5. Подтвердите, затем проверьте расписание и счёт. Генерация повторно не должна вернуть старые дни.
6. В группе «04 Подорожание» проверьте задачу по увеличению оплаченного месяца. В «08 Проверка справки» доступно отдельное неразобранное отсутствие.

Локальная проверка не отправляет SMS, не вызывает F.Doc и не проводит реальные платежи. Прод развёртывается отдельным действием после приёмки.
