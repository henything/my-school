# Тестовый контур

Адрес: <https://test.195.133.56.68.sslip.io/login>. Он размещён на том же VDS, что и прод, но использует отдельные каталог `/var/www/azbuka-staging`, пользователя `azbukastage`, базу `azbuka_stage`, сервис `azbuka-staging.service` и порт 3001. Прод работает на порту 3000.

Тестовый контур не содержит копии боевой базы, ключей ЮKassa или расписания ежемесячного формирования счетов. `prisma/seed.ts` здесь не запускается. После первого развёртывания создаются только тестовая школа и один супер-администратор. Исходный пароль хранится на сервере в `/root/azbuka-staging-initial-login` с правами 0600; не добавляйте его в репозиторий или документацию.

Первичная настройка сервера:

```bash
pnpm stage:setup
```

Развёртывание текущего рабочего дерева (после локальных lint, typecheck и тестов):

```bash
pnpm stage:deploy
```

Если те же проверки уже были выполнены в этом рабочем дереве:

```bash
scripts/deploy-staging.sh --skip-precheck
```

Проверка после развёртывания:

```bash
curl -fsSI https://test.195.133.56.68.sslip.io/login
ssh azbuka-prod 'systemctl is-active azbuka-staging.service'
```

Скрипт настройки выпускает отдельный сертификат Let's Encrypt для тестового адреса. Настройки F.Doc для тестового контура следует добавлять только в `/var/www/azbuka-staging/.env`; они не должны попадать в Git или продовую `.env`.
