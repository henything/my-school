# Льгота до проверки документа

## Правила

- При выборе категории в регистрации нужен PDF/JPEG/PNG/WebP до 5 МБ. Проверяются размер и содержимое файла. Без льготы файл не нужен.
- Файл доступен своему родителю и администраторам школы, но не тренеру. Хранится в закрытой таблице БД и входит в резервную копию базы.
- Скидка 10% применяется ко всем новым счетам семьи за первый расчётный месяц при наличии документа. Месяц фиксируется при первом выставлении счёта, а не при регистрации. Повторная заявка не даёт ещё один первый месяц.
- Пока нет решения, в последующих месяцах скидки нет. Подтверждение включает бессрочную скидку для новых счетов; отказ сохраняет скидку первого месяца, со следующего месяца её нет. Старые счета не пересчитываются.
- Для двух детей скидка обоим; одобрение требует две карточки одной семьи. Скидки не складываются.
- Администратору создаётся одна открытая задача на родителя со ссылкой на проверку и файл. Решение закрывает задачу. Просто закрыть задачу без решения нельзя.
- Старые подтверждённые льготы работают по-прежнему; ожидающие без файла временную скидку не получают.

## Проверка

Тесты файлов и доступа; первый/следующий месяц для всех решений; переход года; двое детей; повторные заявки и счета; неизменность выставленных счетов; задача и версия карточки. Интеграционная проверка с локальной БД и проверка интерфейса.

## Выпуск

Добавочная миграция без пересчёта старых данных. Pipeline заканчивается локальной проверкой. Прод публикуется отдельно после deploy.
